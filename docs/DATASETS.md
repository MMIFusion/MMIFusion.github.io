# 数据资源目录

站内地址：https://mmifusion.github.io/datasets.html

主站数据文件为 `data/datasets.json`，页面由 `scripts/datasets.py` 构建。`assets/datasets.css` 和 `assets/datasets.js` 仅在数据资源页加载，页头、栏目导航、时间栏、扫码窗口与页脚复用主站公共组件。

## 初次整合与来源

资料来自本地 `MMIFusion/Datasets/docs/data/datasets.json`，原仓库提交 `7f997a2`。此次完整导入 111 项资源、6 个研究方向、16 组任务和 110 张原图。仅将图片的本地路径映射到 `assets/dataset-catalog/`；名称、标题、论文、团队作者、发表信息、描述、链接、下载补充说明、开放状态与图片来源保持原样。整合不表示重新核验所有学术信息。

原始内容与图片摘要见 `data/datasets-provenance.json`，原项目许可全文保留于 `docs/DATASETS-LICENSE.txt`。整理作者为汐萌、囗〇，版权属于公众号「多模态信息融合」；第三方论文、数据和图片继续遵循各自原始许可。

重新核对导入内容（只读）可运行：

```sh
python3 scripts/import_datasets.py ../Datasets/docs --check
```

显式去掉 `--check` 会从给定目录重新导入，覆盖主站的数据副本。主站已有后续维护时，不要用旧归档覆盖新内容。日常构建与 GitHub Actions 不依赖旁边的 Datasets 文件夹。

## 后续维护

在主站修改 `data/datasets.json` 并放入对应原图，然后运行 `python3 scripts/build.py` 与 `python3 scripts/check.py`。保留既有条目的 `id`；新增资源需提供全部论文作者（按原文顺序）、团队机构、原论文或官方项目链接、图片来源，以及资源类型和使用许可。不确定的发表或开放状态应明确标注，不能猜测。

旧仓库保存历史资料与原图；后续站内目录以主站数据文件为准。`datasets-provenance.json` 记录初始导入批次及原图摘要，不把后续新增资源伪装成这次导入。若确需替换已导入原图，应核对新来源并同步对应摘要及记录。

## 使用与回退

- 搜索支持名称、论文、任务、团队、作者与介绍中的多个关键词。
- 按 6 个方向、16 组任务组合筛选，可按整理顺序、名称或发表年份排序；年份来自原有发表字段。
- 每次显示 12 项，可继续加载；筛选、排序和显示页数保存在 URL。
- `datasets.html#dataset=msrs` 等稳定地址直接打开对应档案；关闭、浏览器后退与前进均保持目录状态。
- 档案保留完整团队作者、描述、下载补充说明和全部原图，可复制条目地址，也可转到站内论文检索和勘误表单。
- 无 JavaScript 时，111 项完整内容直接显示，可通过每项的原生折叠面板阅读全文。筛选与弹窗初始化失败也不会隐藏原始目录。
- 图片读取失败时显示说明，文字和来源链接继续可用。没有额外的数据请求、登录或第三方脚本依赖。

检验时关注旧条目深链接、筛选组合、排序/加载更多、全文与作者信息、全部图片、模态弹窗焦点/返回、手机宽度，以及无脚本回退。
